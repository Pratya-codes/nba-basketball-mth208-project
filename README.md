# Basketball By The Numbers
The Folder, Project_MTH208_Team_4 contains all the necessary files.
It contains the file Report_MTH208_Team4.
complete_data_for_referance this folder contains all the csv files,
10 csv files containing team wise data for past 10 seasons. 
1 csv file cotaining player wise data for 2024-25 season.

The folder 'code' contains 2 codes, EDA.R and scraping.R.
EDA.R contains the Exploratory data analysis. To run this code,
set the working directory to the Folder 'code'.

scraping.R contains the scraping code. To run this code, 
set the working directory to the Folder 'code'. The new csv files,
will be saved in the empty Folder 'data'. The purpose of the Folder 'data' is to,
just save the csv files created by running the scraping code.

Folder named 'app1' contain the shiny app code named 'app.R'.
This app can be diretly run by opening 'app.R', setting the working directory to folder 'app1', and clicking on run app.
The app.R is for the first objective of our project proposal.
Else, if you want to run the app in console, then first set the working directory to the folder, 'Project_MTH208_Team_4',
and then run the command, 
shiny::runApp("app1")

Folder named 'app2' contain the shiny app code named 'app.R'.
This app can be diretly run by opening 'app.R', setting the working directory to folder 'app2', and clicking on run app.
The app.R is for the Second objective of our project proposal.
Else, if you want to run the app in console, then first set the working directory to the folder, 'Project_MTH208_Team_4',
and then run the command, 
shiny::runApp("app2")
